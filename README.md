# Happy Birthday Jaswal 🎂

An extremely late, extremely sorry, extremely unhinged birthday storybook for Navya Jaswal.

One flow, start to finish: boot-screen emergency → SORRY → a storybook with mini games (coconut climb, arcade racer, whack-a-Jaswal, rigged quiz) → the Singapore shot (with instant replay) → HAPPY BIRTHDAY (blow the candles into your mic) → the letter that never arrived → **PSYCH**.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 — volume up, laptop recommended.

Jump to any scene while testing with `?scene=N` (0–11).

## Deploy

Import the repo on [Vercel](https://vercel.com/new) — it's a standard Next.js app, no env vars needed. Or `npx vercel --prod`.

## Media

Original photos and video live in the repo root. Web-optimised versions (and the cropped face stickers / shot loop) are in `public/media/`.
